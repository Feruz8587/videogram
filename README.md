# Videogram

Instagram'га ўхшаш платформа: Node.js + Express + SQLite, фронтенд — соф HTML/CSS/JS (қоронғи фон, glass дизайн).

## Ишга тушириш

```bash
npm install
npm start
```

Кейин браузерда: http://localhost:3000

Node.js 18 ёки юқориси керак. Порт ўзгартириш: `PORT=8080 npm start`

## Имкониятлар

- Рўйхатдан ўтиш / кириш (username + парол, парол bcrypt билан сақланади)
- Видео ва расм жойлаш (200MB гача), лентада видео экранда кўринганда автоматик ўйнайди
- Лайк (расм устига икки марта босиш ҳам), изоҳлар, постни ўчириш
- Профиль: аватар, ном, bio, постлар тўри
- Қидирув: рўйхатдан ўтган ҳамма одам шу ерда чиқади, ном ёки username бўйича қидириш мумкин
- Обуна бўлиш / обунани бекор қилиш (лента: «Обуналар» ва «Ҳаммаси»)
- Шахсий хабарлар (ўқилмаган хабарлар белгиси билан)

Дастлаб база бўш: одамлар ўзлари рўйхатдан ўтгач пайдо бўлади.

## Папкалар

```
server.js        — бутун backend (API + SQLite)
public/          — index.html, style.css, app.js
data/            — SQLite база ва махфий калит (автоматик яратилади)
uploads/         — юкланган видео ва расмлар (автоматик яратилади)
```

## Интернетга чиқаришдан олдин

- `JWT_SECRET` муҳит ўзгарувчисини ўзингизнинг узун тасодифий қийматингизга қўйинг (қўймасангиз `data/secret.key` ичида автоматик яратилади).
- HTTPS орқасида ишлатинг (Nginx, Caddy ёки Render/Railway/Fly.io).
- `data/` ва `uploads/` папкаларини доимий диск (volume) га қўйинг, акс ҳолда ҳостинг қайта ишга тушганда йўқолади.
- Google орқали кириш қўшиш учун Google Cloud'да OAuth client ID керак бўлади; ҳозирча оддий аккаунтлар ишлайди.
